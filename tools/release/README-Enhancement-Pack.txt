SOLDIERS: HEROES OF WORLD WAR II: ENHANCEMENT PACK 1.2
======================================================
A fan-made patch for the GOG version of the game (version 1.28.3E). With it you get the Enhanced
Edition (R1.28.8), the developers' final version, sharp on a 4K screen, with HD textures and modern
keys, and no Steam needed.


Installation
------------
1. Install the GOG game.
2. Unpack all three parts into your game folder (the folder that holds Soldiers.exe).
   Choose "yes" when asked to overwrite files.
3. Linux only: set this environment variable in your game launcher:  WINEDLLOVERRIDES=d3d9=n,b
4. Start the game.

The pack's settings are in uiscale.ini in the game folder; each line is explained there.
